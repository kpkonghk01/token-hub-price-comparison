點樣比先算公道

每間 provider 計費方式都唔同（峰谷、快取、階梯、分辨率），所以下面每個假設都攤開講清楚。你改假設，個表就跟住重算。

比較方法：一句話講晒
  • 綜合單價＝(R × 有效輸入價 + 輸出價) ÷ (R + 1)，R 就係上面個「輸入:輸出 比例」。單一數字先可以跨 provider 排名。
  • 有效輸入價＝輸入價 ×(1 − 快取命中率) + 快取價 × 快取命中率。冇公佈快取價嘅型號，一律當冇快取（用足全價），唔會靠估。
  • 悅智 TokenHub 份報價單淨係畀折扣率，冇絕對價。所以佢嘅價 ＝ 原廠基準價 × 折扣率。折扣率係按原廠計，同一原廠所有型號共用。
  • 峰谷：只有 DeepSeek 原廠直供分峰谷（北京 9-12、14-18 為高峰，價錢係空閒兩倍）。老細講過保守起見可以全部當高峰計 — 上面個切換掣做到。
  • 同一 model 唔同 provider 冇上架嘅，個格留白，唔會硬砌對照。
  • 虛線底嘅數字（悅智、現用供應商）係推算價 ＝ 基準價 × 折扣，唔係對方直接報嘅絕對價。實線嘅係報價表照抄。
  • 向量模型（Gemini Embedding $0.15／騰訊 Kinfra $0.07–0.252）唔屬於 text→text，冇收入本表。
「原廠基準價」逐個來源交代

悅智嘅折扣要有個底價先算到。呢個底價每一行都標明出處：

官方定價頁Google Gemini：直接用 Gemini Developer API 定價（paid tier、standard，非 Batch/Flex/Priority）。呢個係唯一一份真·官方文件。
騰訊國際站Anthropic Claude、OpenAI GPT、xAI Grok：騰訊國際站報價同原廠美元目錄價完全一致（Opus 5 = $5/$25、Sonnet 5 = $3/$15、Haiku 4.5 = $1/$5），所以直接當原廠價用。
騰訊新加坡GLM／Kimi／MiniMax／混元：騰訊「語言模型」平台新加坡區報價係整數美元（例：GLM-5.3 = 1.4/4.4、Kimi K3 = 3/15），最似原廠國際版目錄價，用嚟做基準。
騰訊廣州DeepSeek V3.2：廣州區 0.28/0.42 同 DeepSeek 官方美元價一致；新加坡區反而貴一倍（0.57/1.71）。

凡標住 推定 嘅，即係嗰個基準價唔係直接嚟自原廠文件，而係由騰訊報價推回去 — 睇趨勢 OK，落單前要同供應商 double check。

三個騰訊欄位有咩分別
  • 騰訊·新加坡 / 廣州：騰訊雲「語言模型」平台（模型价格.md）。同一隻 model 不同 region 價錢可以差成倍，DeepSeek V3.2 就係例子。
  • 騰訊·國際站：騰訊雲「VOD AIGC 大模型」平台（模型单价 報價表）。呢個平台先有 Gemini、Claude、GPT、Grok、Sora、Veo 呢啲海外模型。原表同時列國內站人民幣同國際站美元價，本表只取美元。
  • 騰訊·混元平台（生圖/生片分頁）：模型价格.md 嘅視覺模型段，按 token 用量折算成每張／每秒。
  • 國際站備註：港澳免稅，其餘國家要另外交稅費 — 呢個表未計稅。
未計入嘅嘢（落單前記得問）
  • 稅：悅智報價單寫明海外模型如用人民幣結算要加 15 個點（8% 非貿付匯稅 + 1% 附加稅 + 6% 增值稅），公式係 美金金額 × 匯率 × 1.15。用美元結算就唔使。騰訊國際站港澳免稅。
  • Batch / Flex / Priority：Google 官方 Batch 平一半，Flex、Priority 各有價目。本表一律只計 Standard。
  • 前置條件：悅智全部係預付，用量大 case by case；AWS Bedrock／GCP Vertex／Azure 通路寫「用量申請」，即係要傾。報價有效期 15–30 日。
  • 工具費：Google Search grounding（Gemini 3.x 每月 5,000 次免費，之後 $14/1,000 次）、Maps grounding、file search 嘅 embedding 費，全部另計。
  • 限時優惠：GLM-5.3-Flash 至 2026-09-10 23:59 半價；OpenAI 5.6-sol 26.9.2 後限時優惠；Gemini 3.6/3.7/3.8 Flash 2027-01-01 起加價一倍 — 表入面兩個價都列咗。
  • 雜項按次費：可靈人臉識別、Vidu 主體識別／聲音複刻、Claude Web 搜索等，騰訊另有按次收費。
呢個檔點樣更新

整個表由三個檔砌出嚟，全部喺同一個資料夾入面：

build/build_data.py所有報價數字嘅唯一出處。騰訊嗰啲圖片報價表係人手轉錄咗入去呢度。改價、加型號都係改呢個檔。
data.json跑 python3 build/build_data.py 產生。結構化報價，想倒入 Excel 或者第二個系統可以直接用。
index.html單一檔案、自足、離線都開得（字體要上網，冇網就用系統字體，唔影響數字）。用 build/template.html 加 data.json 砌成。

重新產生：跑 python3 build/build_data.py，再將 data.json 塞返入 build/template.html 嗰個 payload 佔位符位置就得（build/make.py 幫你做晒）。
