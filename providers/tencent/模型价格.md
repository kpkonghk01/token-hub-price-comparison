#### 3D 生成

**世界模型** 采用 **按 Token 计费** 方式，后付费方式下，结算周期为小时结。

同一模型在不同参数配置下 Token 消耗数可能存在差异，生成费用可根据所选模型版本及参数，参考表格中的参数与费用进行测算，费用由 **Token 单价**与 **Token 用量** 共同决定，具体计算公式为：

`参考费用 = Token 用量 x` `Token` `单价`
